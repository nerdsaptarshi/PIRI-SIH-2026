# PIRI — Predictive Infrastructure Risk Intelligence

AI-powered project-monitoring prototype for **SIH 2026 Problem Statement 103**.

PIRI combines project progress, cost, schedule and implementation indicators into a model-driven risk score, early-warning alerts, sector analytics and explainable model drivers (SHAP).

## Important data note

The repository currently contains **synthetic demonstration data** generated by `scripts/seed_and_train.py`. It is **not PAIMANA/OCMS data** and must not be presented as official government data. Real PAIMANA/OCMS integration should only be connected through authorized data/API access.

## Architecture

`GitHub → Render Web Service → FastAPI → PostgreSQL → scikit-learn + SHAP → PIRI Dashboard`

The dashboard and API are served from the same web service.

## Deploy to Render

1. Push this repository to GitHub.
2. In Render, choose **New → Blueprint** and select the repository.
3. Render reads `render.yaml` and creates:
   - `piri-ai-monitoring` — Python web service
   - `piri-postgres` — PostgreSQL database
4. Keep the web service on the **Free** plan for the SIH prototype.
5. The first deployment seeds synthetic demo data and trains the models.
6. Open the generated `onrender.com` URL.

The `render.yaml` uses a pre-deploy bootstrap so that an empty database is seeded once. If the database already contains project/outcome records, the bootstrap retrains from those stored records without deleting them.

## Local run without Docker

```bash
python -m venv .venv
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python scripts/seed_and_train.py
uvicorn backend.main:app --reload
```

Open `http://127.0.0.1:8000`.

## ML and explainability

The prototype uses scikit-learn Random Forest models for:

- cost-overrun classification
- schedule-delay classification
- cost-overrun percentage regression
- delay-month regression

SHAP is used to explain tree-model contributions for the selected project. SHAP contribution is **not causal attribution**.
